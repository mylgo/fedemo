# 实现 Excel 导出功能

使用如下数据实现 Excel 导出功能：

```json
{
  "excelName": "IPO数据",
  "sheetList": [
    {
      "sheetName": " 5-1应收账款-按种类 ",
      "cells": [ "E4 ", "F4 ", "G4 " "H5 ", "L5 ", "M5 "],
      "errorType": "数据类型错误"
    },
    {
      "sheetName": " 6-应收账款-期末余额前几名单位情况 ",
      "cells": ["C5 ", "D5 ", "E5 ", "F5 "],
      "errorType": "数据类型错误"
    },
    {
      "sheetName": " 8-应收票据-期末已背书或贴现但尚未到期 ",
      "cells": ["B5 ", "C5 ", "D5 ", "E5 ", "F5 ", "G5 ", "H5 ", "I5 "],
      "errorType": "数据类型错误"
    }
  ]
}
```

# 业务要求

- Excel 名称取 `excelName` 字段
- Excel 内容分 3 列
- 第 1 列第 1 行标题名称为 `表格名称` 内容取 `sheetName` 字段
- 第 2 列第 1 行标题名称为 `错误类型` 内容取 `errorType` 字段
- 第 3 列第 1 行标题名称为 `错误的单元格坐标` 内容取 `cells` 字段并以 `，` 分隔

# 技术栈

- Vue.js@2
- element-ui
