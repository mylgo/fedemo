# Chrome 导出 Excel 功能

## 项目说明

使用 Vue2.js 和 Element UI 实现的 Chrome 浏览器导出 Excel 功能，用于导出财务报表错误检测结果。

## 功能特性

### 核心功能

- ✅ 错误数据表格展示（序号、表格名称、错误类型、错误的单元格坐标）
- ✅ 一键导出为 Excel 文件（文件名：错误报告.xlsx）
- ✅ 添加/删除错误记录
- ✅ 重置为默认测试数据

### 技术栈

- **Vue.js 2.6.14**: 前端框架
- **Element UI**: UI 组件库
- **SheetJS (xlsx)**: Excel 文件生成库

## 使用方法

### 1. 本地测试

直接用浏览器打开 `index.html` 文件即可。

### 2. HTTP 服务器方式（推荐）

```bash
# 方式一：使用 Python
python -m http.server 8080

# 方式二：使用 Node.js
npx http-server -p 8080

# 方式三：使用 PHP
php -S localhost:8080
```

然后访问：`http://localhost:8080`

### 3. VS Code Live Server

如果使用 VS Code，可以安装 Live Server 插件，右键点击 `index.html` 选择 "Open with Live Server"。

## 操作说明

1. **查看错误列表**: 页面加载后会显示所有错误记录
2. **添加错误记录**: 点击"添加错误记录"按钮，按照提示输入信息
3. **删除记录**: 点击表格中每行的"删除"按钮
4. **导出 Excel**: 点击"导出为 Excel"按钮，文件将自动下载为【错误报告.xlsx】
5. **重置数据**: 点击"重置数据"按钮恢复默认测试数据

## 导出的 Excel 格式

导出的 Excel 文件包含以下列：

- **序号**: 错误记录的序号
- **表格名称**: 出错的财务报表名称
- **错误类型**: 错误的分类
- **错误的单元格坐标**: 逗号分隔的单元格位置列表

## 注意事项

1. **CDN 依赖**: 项目使用 CDN 加载依赖库，需要网络连接
2. **浏览器权限**: 导出文件时浏览器可能会请求下载权限
3. **文件格式**: 导出的文件为标准的 `.xlsx` 格式，可用 Excel、WPS 等软件打开

## 常见问题

### Q: 点击导出按钮没有反应？

A: 请检查浏览器控制台是否有错误信息，确保网络连接正常，CDN 资源能够正常加载。

### Q: 如何修改导出的文件名？

A: 编辑 `app.js` 文件中的 `exportToExcel` 方法，修改这一行：

```javascript
XLSX.writeFile(workbook, '错误报告.xlsx')
```

### Q: 如何调整列宽？

A: 编辑 `app.js` 文件中的 `worksheet['!cols']` 配置：

```javascript
worksheet['!cols'] = [
  { wch: 10 }, // 序号列宽度
  { wch: 20 }, // 表格名称列宽度
  { wch: 20 }, // 错误类型列宽度
  { wch: 40 }, // 单元格坐标列宽度
]
```
